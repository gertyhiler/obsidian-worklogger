# Security

Worklogger operates on local Markdown documents. It does not need network access or collect telemetry. Note contents must be treated as untrusted input, never executed as code or inserted as raw HTML.

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/gertyhiler/obsidian-worklogger/security/advisories/new) if enabled. If unavailable, open an issue asking for a private reporting channel without publishing exploit details or private data. Include affected versions and a synthetic reproduction, not a real vault.

The latest published release is the supported version. Keep independent backups of important notes.
