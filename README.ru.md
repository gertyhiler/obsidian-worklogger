# Worklogger для Obsidian

[English](README.md)

Простой табель прямо в заметке. Выделяйте время мышкой, меняйте длительность и смотрите расчёт **часы × ставка = стоимость**. Данные хранятся в JSON внутри того же Markdown-документа.


![Worklogger](docs/assets/worklogger.png)

## Возможности

- Создание, перемещение и растягивание интервалов; название и описание каждой записи.
- Фиксированный период и ширина сетки на 7 или 14 дней.
- Пересекающиеся интервалы учитываются один раз; обе границы периода включены.
- Ставка и валюта каждого табеля: RUB, USD, EUR, GBP, CNY, KZT, GEL, TRY, AED, UAH, JPY.
- Русский и английский интерфейс, автоматический выбор языка.
- Подстановка `{.Time}`, `{.Rate}` и `{.Cost}` в тексте этой же заметки в режиме чтения.
- Без аккаунтов, телеметрии, внешних сервисов и конвертации валют.

Релиз рассчитан на **настольный Obsidian 1.8.7 и новее**. Мобильные взаимодействия не проверены; плагин помечен как desktop-only.

## Установка

Плагин пока не опубликован в каталоге community plugins Obsidian.

**Вручную:** скачайте `main.js`, `manifest.json` и `styles.css` из [релиза](https://github.com/gertyhiler/obsidian-worklogger/releases), положите их в `<vault>/.obsidian/plugins/worklogger/`, перезапустите Obsidian и включите Worklogger в настройках сторонних плагинов.

**Через BRAT:** установите [BRAT](https://github.com/TfTHacker/obsidian42-brat), добавьте `https://github.com/gertyhiler/obsidian-worklogger` как beta plugin repository и включите Worklogger. Для этого нужен опубликованный релиз с тремя файлами плагина.

## Использование

Вызовите команду вставки табеля **Worklogger** из палитры команд или вставьте блок ниже. Переключитесь в режим чтения.

````markdown
```worklogger
{
  "id": "example-worklog",
  "version": 1,
  "start": "2026-01-05",
  "end": "2026-01-18",
  "days": 14,
  "hourlyRate": 100,
  "currency": "USD",
  "events": [
    {
      "id": "example-1",
      "title": "Варианты дизайна",
      "description": "Сравнить два варианта компоновки",
      "date": "2026-01-05",
      "start": 600,
      "end": 780
    }
  ]
}
```

Итого: {.Time} × {.Rate} = {.Cost}
````

Время задаётся в минутах после полуночи: `600` — 10:00, `1440` — 24:00. Даты календарные, локальные. Интервал относится к одному дню; ночную работу разделяйте по полуночи. В примере получается 3 часа и 300 USD.

Протяните мышкой по пустому месту, чтобы добавить время. Перетаскивайте блок для перемещения, тяните его край для изменения длительности. Клик по блоку или плавающая кнопка **+** открывает редактор. Изменения сохраняются в исходный блок заметки. Переключатель 7/14 меняет ширину колонок, а не границы отчётного периода.

Подстановки относятся только к текущему Markdown-документу и отображаются в режиме чтения. В исходнике остаётся текст `{.Time}`, `{.Rate}` или `{.Cost}`. Используйте один табель на заметку, чтобы итог был однозначным. Во внешних редакторах и экспортированном Markdown подстановки не рассчитываются.

Язык и валюту по умолчанию можно выбрать в настройках Worklogger. У существующих табелей валюта сохраняется. Смена валюты табеля меняет обозначение суммы; ставка **не конвертируется**, курсы валют не загружаются.

## Данные

Интервалы, период, ставка и валюта находятся в заметке. Настройки плагина сохраняются отдельно в локальном `data.json`. Используйте обычное резервное копирование и синхронизацию vault: у Worklogger нет собственного сервиса для этого. Избегайте одновременного редактирования одной заметки на нескольких устройствах.

Все примеры в репозитории вымышленные. Не прикладывайте приватные заметки к issues.

## Разработка

Нужны Node.js 22 или новее и npm.

```sh
npm ci
npm run check
npm run build
```

Скопируйте собранный `main.js`, `manifest.json` и `styles.css` в `.obsidian/plugins/worklogger/` тестового vault. Сначала проверяйте изменения на временной заметке.

Правила участия: [CONTRIBUTING.md](CONTRIBUTING.md). Безопасность: [SECURITY.md](SECURITY.md). [Архитектурное решение](docs/adr/0001-inline-worklogs.md). Теги релизов совпадают с версией без префикса `v`, например `1.0.0`. Workflow проверяет версии, выполняет проверки и публикует три файла плагина.
